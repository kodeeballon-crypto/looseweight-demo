# Plan Chat & Lifestyle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 饮食周表右侧加入 AI 对话面板（预览 → 应用的局部修改 + 长期记忆），并在档案中加入生活节奏，让生成的食谱对上班族可执行。

**Architecture:** 纯逻辑放 `domain/`（lifestyle、planChat），AI prompt/解析放 `ai/`，状态放 zustand store，UI 为 `PlanChat` 组件 + `WeekTable` 预览高亮 + `MealPlan` 两栏布局。pending 方案只存在于 `MealPlan` 的 React state。

**Tech Stack:** React 19 + TypeScript + zustand(persist) + vitest + Vanilla CSS。

**Spec:** `docs/superpowers/specs/2026-10-13-plan-chat-design.md`

## Global Constraints

- 不新增 npm 依赖。
- `planMemory` 上限 12 条；`planChat` 上限 30 条；发给 AI 的历史最多 6 条。
- 对话调用：`timeoutMs: 45000, json: true, temperature: 0.6`。
- 记忆单条截断 30 字，每次 add/remove 各最多 5 条；change 的 kcal 合法范围 30–1500。
- 旧数据无 `profile.lifestyle` 时使用 `DEFAULT_LIFESTYLE = { routine:'office', breakfast:'quick', lunch:'takeout', dinnerMinutes:15 }`。
- 所有交互元素有唯一 id（`#chat-input` `#chat-send` `#chat-apply` `#chat-discard` `#chat-clear` `#plan-chat-fab`）。
- 每个任务结束：`npm test` 全绿 + `npx tsc -b` 无错 + commit。
