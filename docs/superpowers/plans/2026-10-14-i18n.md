# 中英文双语支持 (i18n) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为应用提供无缝的中英文双语切换功能（界面、状态标签、图表、校验提示、Toast、系统弹窗及 AI 生成内容），用户语言偏好持久化存储在 localStorage，默认根据浏览器语言自动适配。

**Architecture:** 采用方案 A（轻量原生 TypeScript 字典 + 强类型推导）：`src/i18n/` 模块提供 `useLang` Zustand store、`zh.ts` 和 `en.ts` 双语字典及 `useT` / `getT` 工具；重构领域常量与模型支持多语言取值；AI 提示词在英文模式下注入输出英文指令；侧栏品牌区与设置页顶部挂载双语切换组件。

**Tech Stack:** React 19, TypeScript 5+, Zustand 5, Vitest, ECharts 6.

## Global Constraints

- 不引入 `react-i18next` 等外部 i18n 重量级依赖，使用纯 TypeScript 原生字典与类型推导。
- `en.ts` 必须严格实现 `BaseDict` 接口，任何中英字典 key 缺失在编译期报错。
- 用户语言偏好独立保存于 `localStorage.getItem('looseweight-lang')`，不受数据导入/清空影响。
- AI 生成英文时保持中式家常减脂特色，仅输出语言使用英文。
- 历史已生成的周表、训练记录、打卡记录鼓励语保留原有语言，不强制覆盖。
- 所有修改必须保持原有 146 个测试通过，且 `npm run build` 无 TypeScript 错误。

Create `src/i18n/store.ts`:
```ts
import { create } from 'zustand';
import type { Lang } from './types';

export const LANG_STORAGE_KEY = 'looseweight-lang';

export function detectBrowserLang(): Lang {
  if (typeof window === 'undefined' || !window.navigator) return 'zh';
  const navLang = window.navigator.language || '';
  return navLang.toLowerCase().startsWith('zh') ? 'zh' : 'en';
}

interface LangState {
  lang: Lang;
  setLang: (lang: Lang) => void;
}

export const useLang = create<LangState>((set) => {
  let initial: Lang = 'zh';
  try {
    const saved = localStorage.getItem(LANG_STORAGE_KEY) as Lang | null;
    initial = saved === 'zh' || saved === 'en' ? saved : detectBrowserLang();
  } catch {
    initial = detectBrowserLang();
  }
  return {
    lang: initial,
    setLang: (lang) => {
      try {
        localStorage.setItem(LANG_STORAGE_KEY, lang);
      } catch {
        /* ignore */
      }
      if (typeof document !== 'undefined') {
        document.documentElement.lang = lang === 'zh' ? 'zh-CN' : 'en';
      }
      set({ lang });
    },
  };
});
```

Create `src/i18n/index.ts`:
```ts
import { useLang } from './store';
import { zh } from './zh';
import { en } from './en';
import type { Lang } from './types';

const DICTS = { zh, en };

function resolve(obj: Record<string, unknown>, path: string): string | undefined {
  const parts = path.split('.');
  let curr: unknown = obj;
  for (const p of parts) {
    if (curr && typeof curr === 'object' && p in (curr as Record<string, unknown>)) {
      curr = (curr as Record<string, unknown>)[p];
    } else {
      return undefined;
    }
  }
  return typeof curr === 'string' ? curr : undefined;
}

export function format(template: string, params?: Record<string, string | number>): string {
  if (!params) return template;
  return template.replace(/\{(\w+)\}/g, (_, k) => (k in params ? String(params[k]) : `{${k}}`));
}

export function getT(lang?: Lang) {
  const activeLang = lang ?? useLang.getState().lang;
  const dict = DICTS[activeLang] || DICTS.zh;
  return (key: string, params?: Record<string, string | number>): string => {
    const val = resolve(dict as unknown as Record<string, unknown>, key) ?? resolve(DICTS.zh as unknown as Record<string, unknown>, key);
    if (!val) return key;
    return format(val, params);
  };
}

export function getLang(): Lang {
  return useLang.getState().lang;
}

export function useT() {
  const lang = useLang((s) => s.lang);
  const setLang = useLang((s) => s.setLang);
  const t = getT(lang);
  return { t, lang, setLang };
}

export * from './types';
export * from './store';
```
